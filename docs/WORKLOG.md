# v0.8 작업 기록

한글화: **기타 깎는 노인**. 게임의 한국어 제목은 **나는 도라에몽**, 도라야키 표기는 **팥빵**으로 정리했습니다.

## 텍스트와 이미지

- 대사·시스템 문구 19,040개 항목을 추출·관리하고 현재 디스크에 삽입했습니다. 문자열 경계, 글리프, 인코딩, 폭과 반각 공백 처리를 확인했습니다.
- 기존 번역 검수에서는 65페이지의 2,056개 고유 명령 단위·8,572개 대표 행을 검토했고, 확정한 수정 59건을 반영했습니다. 배포 전에는 전체 삽입 대조와 해당 수정, 숫자·변형·조건부 문구의 집중 검수를 수행했습니다.
- 117개 PVR 텍스처에 한글을 반영했습니다. 원본 글씨 제거용 마스크, 복원 배경, 투명 한글 글씨를 분리해 수정했습니다.
- 타이틀 로고, 선택 메뉴, 조작 안내, 저장·불러오기, 정보창, 달력, 간판, 도구 라벨, 이야기 소품 등을 다뤘습니다.
- 메뉴의 글자 크기·외곽선·색감·배치, `설정`의 크기와 흰 부분, `월`의 입체감과 검은 외곽선, `4월 제1주`의 띄어쓰기, 성공·실패의 열, 중복 수량 단위를 조정했습니다.
- 일기 표지는 입체감을 보완하고 병·캔 등의 라벨은 원본 면적과 기울기에 맞춰 조정했습니다.
- 추출한 대사·이미지·오디오 정보를 관리하는 Windows EXE 제작 도구를 사용했습니다. 이번 공개 저장소에는 이용자가 원본에 적용하는 **패처 EXE와 그 소스**를 배포합니다.

## 자막

- 주제가 8개, 퉁퉁이 노래 6개로 총 14개 음성 자막 구간을 구성했습니다.
- 두 엔딩에 각각 22개 구간을 구성했습니다. 각 엔딩의 제작진 카드 20개와 회사·한글화 크레딧을 처리합니다.
- 노래에는 나눔스퀘어라운드 Bold, 엔딩에는 나눔고딕을 별도로 사용해 작은 글씨의 가독성을 개선했습니다.
- SH-4 코드에서 자막을 그리며 영상·오디오는 그대로 재생합니다. 영상 자막 합성·재인코딩은 하지 않았습니다.
- 엔딩의 **한글화 / 기타 깎는 노인** 표기를 추가했습니다.
- 제작진 이름 43개는 출처를 확인했습니다. 나머지 53개는 조사 후 확정하지 못해 요청에 따라 기존 표기를 유지했으며, 출처 확인 완료로 취급하지 않았습니다.

## 원본 유지와 범위

- DreamPassport·웹 관련 123개 파일은 원본을 유지했습니다.
- 원본 유지로 합의한 G0144, G0355, G0733(로딩 캔), G1295 이미지 그룹은 추가 수정하지 않았습니다.
- 다섯 트랙의 개수·LBA·섹터 크기·트랙 파일 크기를 유지했습니다. 트랙 1~4는 바이트 단위로 같고 트랙 5에만 변경이 있습니다.
- `ADXPACK0.AFS`, `ADXPACK1.AFS`, `DOUGU/ADXPACK1.AFS`, `ENDING00.SFD`, `ENDING01.SFD`는 원본과 같은 바이트를 유지했습니다.
- 게임 자체에서 구동되는 구조로 만들었지만 실물 드림캐스트에서의 실행은 아직 검증하지 않았습니다.

## 배포

원본 CHD → 원본 트랙 검사 → 트랙 5 차분 적용 → 새 CHD 생성 → 내부 무결성·최종 SHA-256 검사의 순서로 동작합니다. 사용자는 Windows 패처 EXE 한 파일과 지정된 원본 CHD를 준비하면 됩니다. 원본·완성 게임 이미지나 개인 저장 데이터는 공개하지 않습니다.
