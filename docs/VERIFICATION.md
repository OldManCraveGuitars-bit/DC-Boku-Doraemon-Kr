## 실제 실행

Windows의 독립 실행형 Flycast에서 게임과 자막을 확인했습니다. RetroArch는 다음 환경에서 확인했습니다.

| 항목 | 환경 |
| --- | --- |
| 프런트엔드 | RetroArch 1.22.2, Git `69a4f0e`, Windows x86_64 |
| 코어 | 수정하지 않은 Flycast libretro |
| 그래픽 | OpenGL, 640×480 |
| 부팅 | 실제 BIOS, 새 부팅. 게임 메모리·강제 저장 상태 주입 없음 |
| 저장 | 복사한 테스트용 VMU를 게임의 원래 메뉴로 불러옴. 원본 개인 저장 데이터 보존 |

확인한 동작은 한글 타이틀·선택 메뉴, 게임 내부 노래 자막, 새 게임 시작과 도입부 대사 3페이지, VMU 불러오기 완료, 4월 제4주 전환, 일반 대사, 일시 정지 메뉴와 정보창입니다. 정보창에서 성공 3회·실패 0회와 팥빵 수량을 확인했습니다. 두 검증 세션은 정상 종료 코드 0으로 끝났습니다.

## 배포 패처

패처 소스의 오류 처리 테스트 11개와 패키징된 EXE의 UI 컨트롤 생성 검사를 통과했습니다. 실제 EXE를 외부 Python·도구 경로 없이 실행해 지정 원본을 한글 경로로 변환했고, 약 116.7초 후 완성 CHD의 크기·SHA-256이 위 검증본과 일치했습니다. CHD 내부 무결성, 원본 보존, 이미 있는 출력 파일의 거부·보존, 임시 트랙 정리도 확인했습니다.

[패처 검증 보고서](verification/patcher-test.json)와 [오류 처리 테스트 결과](verification/unit-tests.txt)에 결과를 기록했습니다. 생성 시험용 중복 CHD는 검증 후 삭제했습니다. UI 검사는 컨트롤 생성 검사이며 창 전체의 시각 검수는 포함하지 않습니다.

## 아직 확인하지 않은 범위

실물 드림캐스트, Android와 다른 그래픽 환경, 전체 캠페인과 모든 분기, 전체 음성의 청취 검수는 미확인입니다. 음성 339개 중 기존 자막·텍스트와 연결되지 않은 27개는 대사 유무를 청취로 확정하지 않았습니다. 이를 자막 누락 27개 또는 음성 대응 완료로 단정하지 않습니다.
